## Turkce

### ozellikler

**Player**
- No kick / touch slowdown
- Custom FOV + hold-to-zoom (C tusu)
- Custom 3rd person kamera mesafesi/yuksekligi
- Ball aimbot — Mouse4 veya Mouse5 basili tutarken topa smooth aim
- Auto goalkeeper — top kaleye gelince otomatik atliyor

**ESP**
- Player ESP (takım renkleriyle)
- Ball ESP (sahadaki tum toplari bulur, en yakin 3'unu gosterir)
- Mesafe limiti
- Crosshair (dot / cross / gap cross / circle)
- Ball trail — topun gecmis yorungesi
- Ball prediction — gelecek yorunge, gravity ve drag dahil
- Move guide — topun inecegi noktaya yesil kosma cizgisi
- Aim lines — rakip oyuncularin baktigi yon
- Radar

### kullanim

Cikan `psomodmenu.dll`'i bir DLL injectorla oyuna inject et. Menu `Insert` tusuyla acilir.

### not

## English


### features

**Player**
- No kick / touch slowdown
- Custom FOV + hold-to-zoom (C key)
- Custom 3rd person camera distance/height
- Ball aimbot — smooth aim to the ball while holding Mouse4 or Mouse5
- Auto goalkeeper — automatically dives when the ball comes to the goal

**ESP**
- Player ESP (with team colors)
- Ball ESP (finds all balls on the field, shows the closest 3)
- Distance limit
- Crosshair (dot / cross / gap cross / circle)
- Ball trail — past trajectory of the ball
- Ball prediction — future trajectory including gravity and drag
- Move guide — green running line to where the ball will land
- Aim lines — direction other players are looking
- Radar

### usage

Inject the generated `psomodmenu.dll` into the game using a DLL injector. The menu opens with the `Insert` key.

### note

SOME FEATURES, SUCH AS SPEED HACK OR POWERSHOT, ARE NO LONGER INCLUDED BECAUSE THEY ARE OVERRIDDEN BY THE SERVER. THEREFORE, THIS VERSION HAS FEWER FEATURES COMPARED TO OUR PREVIOUS MOD MENU.
